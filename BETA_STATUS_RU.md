# OSU!BAND Beta — состояние исходника

Дата: 7 сентября 2026.

## Что изменено

- Beta относится к сборке клиента, а не к сайту. Этот исходник клиента использует канал `lab`; Stable публикуется отдельно.
- В меню клиента конфиги больше не разделены на «от OSU!BAND / от игроков / мои»: используется один список. У каждой записи отображаются автор, роль, Stable/Beta, ревизия и дата.
- В Beta-разделе оставлен понятный переключатель Watermark. Убраны Cloud sync, Open website и Undo из игрового меню.
- Watermark Beta: `OSU!BAND Beta [osuband.dev] / время / пользователь`.
- Клавишу открытия меню можно переназначить в Settings. F8 остаётся зарезервированной для паузы функций.
- Меню имеет безопасный равномерный масштаб 75–135%; если экран меньше, масштаб автоматически ограничивается так, чтобы интерфейс не вылезал за границы.
- Светлая тема затемнена и в общем UI, поэтому изменения применяются и к меню, и к лоадеру.
- В лоадере кнопка `Open osu!lazer` перенесена рядом с `Launch OSU BAND`.
- В runtime добавлен Win32 mutex: второй экземпляр `OSUBAND.exe` не запускается одновременно с первым.
- Beta-конфиг при публикации клиентом явно помечается каналом `lab`.

## Проверено в этой среде

- `npm test` для сайта: 10/10 тестов.
- Отдельно проверена активация ключа реальным Worker-обработчиком на локальной SQLite: создаётся активная подписка обычному пользователю.
- Проверены общий чат подписчиков, карточки профилей, список пользователей в админке, бан/разбан по Discord ID, модерация и `.cfg` для проверки.
- Portable C++ test-core: PASS.
- 60-минутная симуляция Relax: PASS, 28 811 нажатий, максимум 9 элементов в очереди.
- Dear ImGui CPU-renderer успешно собран и отрисовал Configs, Beta, Settings и Loader, включая светлую тему и увеличенный масштаб.

## Что требует Windows-проверки

В этой среде нет MSVC + Windows SDK, поэтому финальные `OSUBAND.exe` и `OSUBAND.Loader.exe` здесь не собраны. После сборки Release x64 нужно проверить на Windows: запуск второго экземпляра, переназначение клавиши, масштабирование, Watermark и длительную сессию в osu!lazer.
